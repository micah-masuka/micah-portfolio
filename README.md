# Portfolio by Micah Masuka

Live site: [micah.digitale-tech.com](https://micah.digitale-tech.com/)

GitHub Pages mirror: [micah-masuka.github.io/Micah-Portfolio](https://micah-masuka.github.io/Micah-Portfolio/)

UX case studies from a Logos Publicity internship, live client sites (Alfresco The Bakery, Verandah Café), Sanex kiosk work, and coursework.

## Run locally

```bash
python3 scripts/serve.py 8080
```

Then open [http://127.0.0.1:8080/](http://127.0.0.1:8080/).

Pushes to `main` publish both the custom-domain deployment and the GitHub Pages mirror. The Pages workflow builds a project-path-aware copy, leaving the custom-domain source unchanged.
